**Overview**

This repository contains my completed submission for **Task 2** of the WGU course **D684: AI Optimization for Computer Scientists**.

Where Task 1 focused on the technical optimization of a model, Task 2 addresses the product development side of delivering an AI solution: translating an optimized model into a viable product, defining how it will be built and released, and planning for its behavior once it is in the hands of real users.

This task is documentation-driven. The deliverable is the product development artifact set rather than executable code.

**Scenario**

An optimized machine learning model has been validated and is ready to move beyond the experimental stage. Leadership now requires a product development plan that explains how the model becomes a deliverable product, what the development lifecycle looks like, how quality will be assured, and how the solution will be maintained and monitored after release.

**Project Objectives**

-Define the product concept, target users, and the problem the AI solution solves

-Establish functional and non-functional requirements for the solution

-Select and justify a software development methodology appropriate to AI product work

-Define the development lifecycle from requirements through deployment

-Plan testing and quality assurance strategy across data, model, and application layers

-Address deployment, monitoring, and model maintenance after release

-Identify ethical, privacy, and risk considerations associated with the solution

**Areas Covered**

**Product Definition**
The problem statement, intended user base, value proposition, and success criteria for the AI-enabled product.

**Requirements Engineering**
Functional requirements describing what the product must do, alongside non-functional requirements covering performance, scalability, reliability, security, and usability.

**Development Methodology**
Selection and justification of a development approach suited to iterative model refinement, where requirements evolve as model behavior is better understood.

**Lifecycle Planning**
The end-to-end path from data acquisition and preparation, through model development and integration, to release and ongoing operation.

**Testing and Quality Assurance**
A layered testing strategy covering data validation, model performance verification, integration testing, and user acceptance criteria.

**Deployment and Maintenance**
Release approach, monitoring for model drift and performance degradation, retraining triggers, and version management.

**Risk, Ethics, and Compliance**
Consideration of bias, fairness, data privacy, transparency, and the regulatory environment applicable to the solution.

**Skills Demonstrated**

-AI product design and requirements definition

-Software development lifecycle planning

-Development methodology selection and justification

-Quality assurance and test strategy design for machine learning systems

-Deployment planning and post-release model monitoring

-Risk assessment and ethical analysis of AI systems

-Technical documentation for stakeholder audiences
